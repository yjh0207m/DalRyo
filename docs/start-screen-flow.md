# 앱 시작 흐름

2026-10-30 작성, 2026-10-31·11-03 변경 반영 (기준 코드: `App.tsx`).

## 화면 결정

- **저장된 로그인이 있으면 시작 화면을 건너뛴다.** 첫 인증 콜백에 로그인 사용자가 있으면 바로 계정을 확인한다(2026-10-31 변경, 이전에는 항상 시작 화면을 먼저 보여 줬다).
  - users 문서가 있으면 프로필(users + character)을 불러와 홈으로 간다.
  - users 문서가 없으면 가입 정보 입력으로 간다.
- **로그인이 없으면 시작 화면(`AuthStartScreen`)을 보여 준다.**
  - 시작하기 → 전화번호 인증 → 인증 완료 후 기존 계정은 홈, 신규 계정은 가입 정보 입력.
  - 첫 인증 콜백이 오기 전에 시작하기를 누르면, 로그아웃으로 보지 않고 콜백을 기다린다.
- 첫 인증 콜백이 올 때까지는 로딩을 보여 줘서, 저장된 로그인이 복원되기 전에 시작 화면이 잠깐 비치지 않는다.
- 인증·가입 화면에서 뒤로 가면 시작 화면으로 돌아온다. 로그인 세션 자체는 지우지 않는다.
- 로그아웃하면 시작 화면으로 돌아간다. 이전 계정의 늦은 프로필 응답은 홈을 다시 열 수 없다.
- 프로필 조회 실패는 재시도 화면으로 안내하며, 기존 계정을 신규 계정으로 보지 않는다.
- 앱이 실행 중인 상태에서 잠깐 다른 앱에 갔다 돌아오면 현재 화면을 유지한다.

## 로딩 화면과 홈 (2026-11-03)

- 시작·로딩·홈 대기 화면은 트리의 같은 자리에 있는 같은 컴포넌트라, 서로 바뀌어도 배경 이미지가 끊기지 않는다.
- 홈은 로딩 화면 아래에서 미리 그려 둔다. 다음 두 가지가 끝나면 로딩 화면을 0.22초 동안 걷는다.
  - 캐릭터: PNG는 이미지 로드, Rive는 재생 시작. 그림을 받지 못한 경우도 끝난 것으로 본다.
  - 이번 주 기록 응답
- 인터넷이 느려도 갇히지 않도록 10초(`HOME_READY_MAX_MS`)가 지나면 걷는다.
- 로딩 화면이 덮여 있는 동안 홈은 화면 읽기 기능에서 가려진다.

## 검증

라우팅 테스트(`__tests__/App.test.tsx`)는 다음을 확인한다.

- 로그인 유지 시 시작 화면 건너뛰기, 로그인 복원 중 시작 화면 숨김, 비로그인 → 전화 인증
- 신규 계정(users 문서 없음)만 가입으로, 조회 실패 시 재시도
- 인증 화면에서 돌아온 뒤 시작하기, 조회 중 로그아웃, 로그아웃 후 시작 화면, 앱 재실행
- 홈을 로딩 화면 아래 미리 그리기, 가려진 동안 화면 읽기 숨김, 10초 제한, 다시 로그인하면 홈을 다시 기다리기
