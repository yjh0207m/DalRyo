# 앱 시작 흐름

2026-10-30 변경.

- 앱을 새로 실행하면 Firebase 로그인 유지 여부와 관계없이 `AuthStartScreen`을 먼저 표시한다.
- 첫 화면의 시작하기 버튼을 누르기 전에는 계정 프로필 조회나 홈 진입을 하지 않는다.
- 시작하기를 누르면 로그인 복원이 끝날 때까지 기다린다. 이미 로그인되어 있으면 준비 중 화면을 표시한 뒤 프로필이 있는 계정은 홈으로, 신규 계정은 가입 정보 입력으로 이동한다.
- 로그인되어 있지 않으면 전화번호 인증 화면으로 이동한다. 인증 완료 후 기존 계정은 홈으로, 신규 계정은 가입 정보 입력으로 이동한다.
- 인증/가입 화면에서 뒤로 돌아가도 시작 버튼을 다시 사용할 수 있다. 로그인 세션 자체를 지우지 않는다.
- 로그아웃하면 첫 화면으로 돌아간다. 이전 계정의 늦은 프로필 응답은 홈을 다시 열 수 없다.
- 프로필 조회 실패는 재시도 화면으로 안내하며 기존 계정을 신규 계정으로 간주하지 않는다.
- 앱이 실행 중인 상태에서 잠깐 다른 앱에 갔다 돌아오는 경우에는 현재 화면을 유지한다.

라우팅 테스트는 로그인 유지, 비로그인, 빠른 시작 클릭, 신규 계정, 조회 실패/재시도, 뒤로 이동/인증 완료, 조회 중 로그아웃, 앱 재실행을 확인한다.

검증: 라우팅 테스트 8개 통과. 전체 211개 중 기존 온보딩 테스트 1개는 빌드 병행 중 hook 시간 제한에 걸렸고, 해당 스위트를 단독 재실행해 5개 모두 통과했다. TypeScript, 변경 파일 ESLint, Android release 빌드 및 APK 서명 검증 통과. 로그인 유지 상태의 에뮬레이터에서 첫 화면 표시와 시작 버튼 후 홈 진입을 확인했다. 실제 로그아웃·SMS 재발송은 하지 않았다.

테스트 APK: `.build-tmp/DalRyo-android-test-20261030-start.apk`. iOS 실기기 화면 검증과 GitHub 업로드는 이번 변경에 포함하지 않았다.
