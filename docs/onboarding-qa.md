# 가입 화면 오류 수정 및 검수

2026-10-30.

## 수정

- 가입 전 단계를 공통 ScrollView로 감쌌다. Android 키보드 높이에서 시스템 창이 이미 줄어든 영역을 제외해 여백을 확보하고, 실제 포커스 입력창의 화면 위치와 스크롤 오프셋을 이용해 입력창을 위로 이동한다. iOS는 KeyboardAvoidingView도 적용한다.
- 다음/건너뛰기/뒤로 이동 시 키보드를 닫고, 새 단계에서는 스크롤을 처음으로 돌린다. Android 기기 뒤로 가기도 이전 단계로 이동한다.
- 동작이 없던 `현재 위치로 설정` 버튼에 위치 권한 요청 → 단발 위치 조회 → 시·도 역지오코딩 → 지역/사투리 선택을 연결했다. 대략적인 위치 권한으로도 조회한다.
- 로딩 표시, 중복 조회 방지, 권한 거절/GPS 실패/통신 실패/국외·미지원 지역 안내를 제공한다. 실패해도 직접 선택으로 진행할 수 있다. 사용자가 직접 지역을 골랐거나 뒤로 이동한 뒤 도착한 위치 응답은 무시한다.
- 선택 없이 서울로 저장되던 초기값을 없애고 명시적으로 지역을 선택하게 했다.
- 키 50~250cm, 몸무게 10~400kg 범위를 해당 단계에서 검증한다. 잘못된 값을 null로 바꿔 조용히 저장하거나 마지막 단계에서만 실패하지 않는다. 건너뛰기는 입력을 비운다.
- 이름·펫 이름은 저장 규칙과 동일하게 20자, 외부 링크는 500자로 제한한다. 실제 업로드 기능이 없는 카메라 표시는 제거했다.
- 생년월일은 기존 저장 모델에도 저장되지 않던 입력이므로 가입 폼과 입력 타입에서 제거했다. 기존 DB 필드나 규칙을 변경하지 않았다.
- 마지막 저장은 ref로 중복 실행을 차단하고 실패 시 재시도할 수 있다. 저장 중 뒤로 이동을 차단한다. 알 애니메이션은 취소·언마운트 시 정리한다.

## 위치 조회

위치 권한을 사용자가 요청한 경우에만 Nominatim reverse API를 호출한다. 이때 좌표가 외부 OpenStreetMap Nominatim 서비스로 전송된다. 위치는 이 기능을 위해 Firebase에 저장하지 않는다. 앱 식별 User-Agent, 한국어 응답, 화면 출처 표시, 동시 요청 공유, 동일 좌표 메모리 캐시, 짧은 재요청 제한, GPS 15초/API 10초 제한을 적용했다. 서비스 장애 시 자동으로 다른 지역을 추정하지 않고 직접 선택을 안내한다.

- https://nominatim.org/release-docs/latest/api/Reverse/
- https://operations.osmfoundation.org/policies/nominatim/

## 검증

- 전체 Jest 35개 스위트/207개 테스트 통과. 새 테스트 10개는 지역 자동 선택·실패·수동 선택·늦은 응답·중복 저장, 대략적 권한·거부·GPS 오류·통신 오류·국외 위치, 지역명 변환·신체 수치 검증을 포함한다.
- Android 에뮬레이터 360×800dp에서 키보드를 띄우고 링크/몸무게 입력창 전체와 다음 버튼이 보이는 것을 직접 확인했다.
- 실제 단말 위치 API와 네트워크 역지오코딩을 통해 서울 자동 선택 성공을 확인했다. 수동 제주 선택 → 알 받기 → 저장 오류 후 재시도 버튼 유지도 확인했다.
- 검수 전용 진입점에서 저장 함수를 오류로 대체했다. 기존 사용자의 프로필·캐릭터는 변경하지 않았다. 검수 전용 진입점은 빌드 전에 제거하고 원본 index.js를 복원했다.
- iOS는 Windows 환경에서 실제 빌드·화면 검증을 하지 않았다.
- 최종 TypeScript·변경 파일 ESLint·diff 검사 통과. Android arm64-v8a/x86_64 release 빌드 및 APK 서명 검증 통과. 소스맵에서 원래 App.tsx 진입점 사용과 검수 진입점 미포함을 확인했다.
- 공유용 APK: `.build-tmp/DalRyo-android-test-20261030-onboarding.apk` (기존 테스트 인증서 사용). GitHub 업로드나 Firebase 규칙 배포는 하지 않았다.
