# 달료 시각 디자인 기준

2026-10-29 · chan · 사용자 수정 사항 반영

**기존 대표 색감인 민트·하늘색·초원을 유지하고, 그 안에서 화면을 세련되게 개선한다.**
캐릭터는 귀엽게, 화면은 세련된 러닝 앱처럼. 이 선호는 브랜드 색 변경을 허용한다는 뜻이 아니다.

- 기본 색: 민트 #22B48F, 연한 민트 #DDF4EC, 하늘 #CBEBF6, 배경 #EAF7FA, 기존 초원 녹색. src/theme/index.ts의 브랜드 색을 임의 교체하지 않는다.
- 앞선 아이보리·포레스트·라임 제안은 사용자 요청에 맞지 않아 철회했다. 수치 패널은 흰색 또는 연한 민트, 숫자는 기존 민트 잉크 색으로 구분한다.
- 홈의 캐릭터 장면, 수치의 계층, 여백, Pretendard 글꼴, 플랫 버튼, 하단 메뉴 구성 개선은 유지한다.
- 캐릭터 장면의 트랙은 장식이며 실제 코스 지도가 아니다. 실제 러닝 수치를 장식용 데이터로 채우지 않는다.
- 기존 동물 그림·소품·최소 움직임은 유지한다. 새로운 리깅이나 과장된 변형을 적용하지 않는다.

공통 토큰은 src/theme/index.ts, 컴포넌트는 src/components/ui/, 장면은 src/components/scene/CompanionScene.tsx를 기준으로 사용한다.

## 커뮤니티·러닝·기록 상세화

- 커뮤니티는 흰 바탕의 사진 중심 피드, 밑줄 탭, 실제 작성자 프로필 행, 응원·댓글·공유·저장 액션으로 구성한다. 프로필 행은 실제 게시물 작성자이며 스토리나 미확인 알림을 만들어 표시하지 않는다. 이미지 없는 글은 텍스트/실제 러닝 수치 패널로 표시한다.
- 러닝은 거리 수치를 가장 크게, 시간·페이스·칼로리를 같은 줄에 배치한다. 기존 하늘·초원과 캐릭터를 유지하고, 하단에 일시정지·재개·종료를 배치한다. 작은 화면에 맞춰 장면과 숫자가 조절된다.
- 기록은 월간 요약과 러닝 저널을 기본으로 표시한다. 캘린더 탭에서 날짜별 필터를 선택하고, 저널로 돌아오면 전체 월 기록을 표시한다. 썸네일과 상세 지도는 저장된 GPS 경로만 사용한다.
