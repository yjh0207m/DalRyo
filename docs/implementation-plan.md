# 남은 앱 기능 구현 계획

2026-10-27 사용자 범위 확인: **남은 앱 기능 전체**. `chan` 유지.
애니메이션은 검수 중이며 다른 동물로 확대하지 않는다.

## 순서와 완료 기준

- [ ] 프로필 사진 선택/업로드/삭제, 캐릭터 이름 변경(서버에서 양쪽 문서 동기화)
- [ ] 알림 항목별 설정, FCM 권한/토큰/포그라운드/탭 이동
- [ ] 공개/팔로잉/내 게시물 피드, 작성/수정/삭제, 이미지·달리기 첨부
- [ ] 응원/취소, 댓글/답글/삭제, 북마크, 공개 프로필/팔로우/검색/랭킹
- [ ] 서버에서 카운터·등급·알림 처리, 조회 권한/비공개 데이터 보호
- [ ] 달리기 기록 상세·실제 지도·GPS 상태·외부 공유
- [ ] 카메라/앨범 + 캐릭터/기록 워터마크 카드, 시스템 공유 화면
- [x] 같이 달리기: 친구에게 요청/수락·거절/나가기/진행 상태·페이스 비교 (배포·두 기기 실주행 검증은 남음)
- [ ] 공원·코스 탐색/선택/기록 연결
- [ ] 마이룸/아이템/꾸미기의 영속 데이터와 실제 메뉴 연결
- [ ] 이후 단계 기능은 의존 서비스와 필요한 외부 설정을 명시하고 구현 가능 범위 진행

각 항목: 화면 → 서비스 → 서버 권한 → 실패/중복 처리 → 테스트 → ADB 검증.
공개 테스트 게시물·타인에게 알림을 보내는 테스트는 실행하지 않는다.
새 코드만을 이유로 완료 처리하지 않으며, 로컬 구현/배포/실기기 검증을 구분한다.

## 확인한 기반

- Firebase `dalryo-dev`, `(default)`, STANDARD, asia-northeast3. 기존 사용자/캐릭터 데이터 사용.
- 휴대폰 로그인·온보딩·GPS 기록·성장 서버·설정·알림 목록·기록 캘린더는 존재한다.
- 커뮤니티 현재는 `users/{uid}/feed` 조회만, 소셜 함수 소스는 비어 있고 export도 없다.
- `users`는 이메일/폰 등 비공개 데이터이므로 소셜 검색을 위해 공개 조회로 열지 않는다.
- 캐릭터 문서는 클라이언트 수정 금지. 이름 변경은 인증된 서버 함수가 두 문서를 원자적으로 갱신한다.
- 사진/카메라/공유/지도에 필요한 네이티브 패키지 추가 후 Android APK 재빌드 필요.
- iOS 빌드/실기기 GPS·푸시·결제 검증에는 해당 플랫폼 환경이 필요하다.
