## 공원 데이터 원칙

- 공원은 Private.coffee Overpass에서 공개 OpenStreetMap 정보만 조회한다. 외부에는 0.01도 격자 중심만 보내며 UID나 정확한 사용자 좌표를 보내지 않는다.
- 캐시 24시간, 사용자별 검색 간격 30초. 공급자 실패 시 7일 이내 캐시가 있으면 오래된 정보임을 표시한다.
- 코스는 `parks/{parkId}/courses`의 실제 등록 데이터만 사용한다. 없는 코스 경로를 생성하지 않는다. 등록 코스가 없으면 3/5/10km 거리 목표로 시작할 수 있다.
- 공원 주간 랭킹은 `onRunCreate`가 한국 시간 월요일 기준으로 집계한다. 원본 러닝·계정 문서를 공개하지 않는다.

## 검증 기준

화면 → 서비스 → 서버 권한 → 실패·중복 처리 → 테스트 → ADB 확인.
코드 구현, 개발 배포, 실제 기기 검증을 구분한다.
공개 테스트 글·타인 알림 전송·실제 결제는 검증 목적으로 실행하지 않는다.
