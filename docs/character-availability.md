# 캐릭터 지급 정책 및 에셋 점검

2026-10-30, Firebase `dalryo-dev` Storage 실물 조회 기준.

## 지급 정책

- 신규 가입 선물: 토끼(`rabbit`), 오리(`duck`) 중 무작위 지급.
- 펭귄을 포함한 나머지 35종: 향후 상점 알 뽑기 획득 대상.
- 상점 알 뽑기, 가격·재화, 확률, 중복 보상, 다중 캐릭터 보유·교체는 아직 구현되지 않았다. 실제 구매나 뽑기는 제공하지 않는다.
- 기존 계정의 캐릭터는 자동 교체하지 않는다.
- 앱의 `STARTER_CHARACTER_TYPES`와 신규 캐릭터 문서 생성 규칙을 두 종류로 제한한다. 클라이언트에서 다른 종을 직접 생성하거나 현재 종을 변경할 수 없다.
- 이 변경은 소스 및 `DalRyo-android-test-20261030-onboarding.apk`에 반영되었다. Firebase 규칙은 아직 배포하지 않았다. 이전 APK는 36종을 지급 대상으로 사용하므로 새 규칙만 먼저 배포하면 가입이 실패할 수 있다.

## 에셋 점검 결과

- 등록 동물: 37종.
- 성장 이미지: 각 동물의 `characters/{type}/{type}_S.png`, `_M.png`, `_L.png`가 모두 존재한다. 총 111개 PNG를 다운로드하고 디코딩 및 모음 이미지 시각 검수했다. 누락·손상은 없었다.
- 아기/어린이/러너의 그림과 포즈는 서로 구분된다. 다만 이미지별 캐릭터 크기·여백 차이가 있으며, 모든 동물이 같은 실루엣이나 의상 맞춤 비율을 갖는 것은 아니다.
- 알은 공통 로컬 `egg.png`를 사용한다.
- 동물별 `characters/{type}/{type}.riv`: 37종 모두 없음. 앱의 승인된 로컬 Rive 레지스트리도 비어 있다.
- 토끼를 포함한 모든 동물은 `CharacterView`의 공통 PNG 호흡·기울기·들썩임·점프·방향 전환·돌 상태·주변 효과 경로를 사용한다. 팔다리를 독립적으로 움직이는 전용 Rive 달리기가 완성되었다는 의미는 아니다.
- 현재 보관함 아이템은 몸에 맞추는 옷 대신 주변 빛/별/잎 장식이다. 임의 의상의 모든 종별 피팅은 검증되지 않았다.
- 111개 그림의 파일·시각 검수와 코드 연결을 확인했다. 37종의 모든 단계·상태를 실제 기기에서 각각 실행한 검수는 아니다.

## 검증

- 신규 지급 무작위 경계: 토끼/오리만 선택.
- 클라이언트 신규 생성: 나머지 35종 거부.
